## 起動

このフォルダーで以下を実行してください。

```powershell
python app.py
```

PythonがPATHにない今回の環境では、付属の `start.ps1` を使用できます。
社員IDを選択後、`list` → `lend` → 内容入力 → `yes` の順に操作します。返却は `return` に貸出IDを指定します。`confirm` と `result` は表示された確認・操作IDを使う再送・結果照会です。終了は `quit`。

初回のみ3社員・3端末のデモデータを作ります。起動ごとの初期化・既存データの削除はしません。DBは本フォルダーのlending.sqlite3。別DBは `python app.py --db 別のファイル.db`。同じDBを使うコンソールを2つ開けば同時操作できます。

## 整合性の仕組み

SQLiteはDB全体の書込を直列化します。BEGIN IMMEDIATEの後に社員・端末・上限を再確認し、貸出または返却の2更新と操作結果の保存をまとめてコミットします。書込中は他の書込要求が最大10秒待機します。これは仕様書の社員／端末単位のロックより広いロックですが、この小規模ローカル版では同じ競合防止を満たします。

操作IDは確認時に発行し、画面に内容とともに表示します。同じIDは1回のみ更新し、再送は元の結果を返します。別の操作IDで過去の貸出を返却しても、返却済みなら現在の端末・貸出を更新しません。
